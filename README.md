# CCBA Copilot Prompt Practice

An interactive, participant-facing dashboard for CCBA executive Microsoft 365 Copilot training.

## Features

- Start Here orientation and prompting foundations
- Eight practical Microsoft 365 Copilot exercises
- Individual copy controls for every prompt
- Downloadable Word and Excel exercise files
- Responsive desktop and mobile layouts
- CCBA branding and theme-aware presentation

## Run locally

Keep `index.html` and the `assets` folder together, then open `index.html` in a modern browser.

## Repository contents

- `index.html` - self-contained dashboard application
- `assets/ccba-logo.png` - CCBA logo
- `assets/CCBA_Q3_2026_Commercial_Business_Review_PreRead.docx` - Word exercise
- `assets/CCBA_Q3_2026_Sales_Revenue_Tracker.xlsx` - Excel exercise

## Access

This repository contains internal training materials and should remain private unless CCBA approves broader distribution.
